# Aufgabenverwaltung

Kundenorientierte Projektmanagement-Plattform für Sportwerk-Workflows.

## Produktkern

- Zentrale Einheit ist der Kunde, nicht das Board.
- Aufgaben können direkt beim Kunden oder optional in Kundenboards entstehen.
- Kommunikation, E-Mails, Dateien und Zeiten werden kunden- und aufgabenbezogen gesammelt.
- Abteilungen sehen nur die für sie relevanten Kunden, Boards, Aufgaben und Auswertungen.

## MVP-Abgrenzung

Der erste MVP umfasst Kundenverwaltung, Aufgaben, Homescreen, Autosave, Aufgabenchat, Labels, Zeiterfassung, einfache Auswertungen, E-Mail-Zuordnung, Rollen, Benachrichtigungen und Aktivitätsverlauf.

Nicht im ersten MVP enthalten sind native Apps, komplexe KI-Funktionen, Rechnungswesen, Kundenportal, öffentliche API und komplexe Kapazitätsplanung.

## Erste Umsetzung

Die aktuelle Sportwerk-Integration ist eine JSX-Konzeptseite unter `/aufgabenverwaltung`.
Der nächste technische Schritt ist ein klickbarer Kundenübersicht-Prototyp mit Mockdaten.
